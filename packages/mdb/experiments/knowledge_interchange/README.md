# Supplied knowledge/operator interchange example

Run this finite host-only example with an installed `mdb-runtime` wheel:

```sh
rtk proxy python -I /absolute/path/to/panel.py --out /absolute/path/to/receipt.json
```

Two banks disagree at the same value-free `Bob/friend/fictional` address. The first returned value selects the second address, and the second selects the third. Bank A reaches Norway through Carol and Rome; bank B reaches Italy through Dave and Oslo. Both are fictional supplied facts. The matrix crosses each bank with an explicit reference host function and an equivalent dispatch-table function. `mode="native"` here identifies the reference ABI; it does not mean a neural model ran or that the dispatch table was extracted from a model.

The runner retains four matrix rows, four three-step chains, missing/stale/ambiguous/wrong-route controls, and a supplied-execution control. It records selected and omitted mass, claim identity, lowering, consumer checksums, and continuation sources. The next address comes from the operator's own state, including when supplied execution overrides the current consumer state.

This is a reproducible mechanics example. It establishes neither learned semantic routing nor model compression. The separate [Qwen producer assay](../../../../../model-experiments/experiments/2026-10-06-fieldlm-knowledge-interchange/) tests a learned native-state writer.
