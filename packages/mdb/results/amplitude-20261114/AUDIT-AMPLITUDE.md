## Top corrections

- **C1. E1 undercuts the "scalar amplitude decides" reading, and the report does not draw this out.** E1 removes the true-direction component on *correct* items (α = 0, so a → 0). Those items keep the argmax on 69–89 %, and the margin falls by only 3–25 % (median M(0)/M0 0.75 / 0.83 / 0.97). Readable wrong items sit at a ≈ 0 and fail. So amplitude along d is roughly sufficient when boosted (0.6B), but it is **not necessary**: most of the margin rides on the rest of the (high-rank) code. "The code at the fixed address has a scalar amplitude, and its size predicts success" should read: "the projection on the item's true-country direction separates correct from wrong, and boosting it repairs some items. It is one component of a high-rank code, not the variable that sets the outcome."
- **C2. The P2 stratum contrast "readable ≈ 0" is close to definitional.** The stratum comes from `country_rank`, which is the country's rank in the readout of the *same* write W_O·v at (L_c, kv_c, carrier) (`scale-20261114/score.py:118-125`). The correct-vs-right-operand AUC is the non-circular part, and it holds. Family-matched (d3/d4 correct only), it is 0.87 / 0.68 / 0.88: the 1.7B value falls below the sealed 0.75 bar.
- **C3. Exact-tie items should be treated as near-ties on every arm.** Three items have M0 = 0.00 with the foil winning the tie: 0.6B d5-093 (A), 1.7B d5-081 (A; already excluded in B) and 1.7B Great Dictator (B readable). Treating them as near-ties gives the following. A right-operand flips 5/8 (0.6B, median α* 3.0, crit 1.08, q75/q25 1.16) and 5/8 (1.7B, median 2.0, crit 0.69, q75/q25 2.8). B 1.7B readable 3/18. No verdict changes.
- **C4. Ladder-slope Spearman is mechanical.** The push is proportional to a, so the slope correlation cannot support the law. Drop it from the "supported" list, or relabel it as a check that d is a direction that helps the truth.
- **C5. "fp32 reproduces α* 30/32, 20/25, 18/19" should be "7/9, 7/12, 3/4 among items that flip".** The rest agree only in that neither path flips.
- **C6. Arm-B counts should be reported per item as well:** true 3 / 4 / 2 items vs random 0 / 3 / 3. Single items dominate the per-arm figures.
- **C7. Custody is incomplete.** Fix by any of: (a) recover the other B shards' records and the replica records from the mrun outputs, if they exist (unverified); (b) name records by shard in `amp.py` (`records-{tag}-{NAME}-{shard}.jsonl`); (c) give `Branches.seal` a project store, so `arms_payload` is stored rather than `absent`. The report's sentence "Every Pool, Branches and core-file record carries custody … Records are in out/<model>/records-*.jsonl" overstates what is committed.
- **C8. Minor.** E1 denominators: 16/72 and 27/86 count items with M0 > 0. There are 72 / 88 / 104 base-correct items, and the fractions are unchanged. The P2 table's 1.7B right-operand n is 10. "At most 3 composers switch" means at most 3 among the top-256 \|effect\| gates. The P4 random baseline is not matched to the candidate pool. The arm-A random null is a random 128-d direction, so it controls for norm only. It is not a direction-specificity control such as a same-size push along another country's direction.

## What holds up (balanced)

- Custody of predictions is clean. Every number in `report.md` that I recomputed reproduces from the raw jsonl. The code implements the prereg as written.
- **0.6B arm A is a real positive.** Boosting the item's own true-country projection flips 5–6 of 8–9 right-operand items. It beats the matched-norm random null clearly: for example, T3 dM is +2.6 vs −0.4 random, and only 1/9 random flips. The flips land at a post-dose amplitude of about 1.0–1.1 class units, the level correct items carry, with tight spread.
- P2's correct-vs-right-operand separation is robust to the twin confound on all three models, and to the family confound on 0.6B and 4B.
- Arm B's negative is solid and well controlled. The back-patch is a true rerun, the random nulls are on equal footing, and the self-null is exactly 0. The repairs do not raise the amplitude.
- §2.3 reproduces exactly and the forecast code matches the memo. On 0.6B and 1.7B, exact SwiGLU on the 8–32 largest-Jacobian gates per layer recovers the 0.58 → 0.88 gap. That is a clean, useful method result. 4B's residual is attention re-reads, which is outside F2 by design.

## Plain verdict on the hypothesis

The memo's hypothesis has four parts: (1) a latent hop variable has a scalar amplitude; (2) the consumer is a thresholded gate bank; (3) chained lookups fail by sub-threshold amplitude; (4) back-patching repairs by re-amplifying. Measured here, only a narrow part survives. On Qwen3-0.6B, the projection of the carrier value onto the item's own true-country direction is lower on wrong items. Boosting it to about the correct-item level flips most right-operand failures, with a reasonably tight critical value. That is a genuine but small (n = 6) threshold-like result. It weakens on 1.7B, where the flips are within noise and a random push flips 4/9, and on 4B, where few items flip and the residual sits in attention re-reads. E1 shows the projection is not necessary for correct answers: removing it costs only 3–25 % of the margin. So it is one helpful component of a high-rank code, not *the* amplitude that decides the hop. Back-patching at the carrier row does not work by re-amplifying (0/39), and it repairs rarely, about as often as random. The gate-switch prediction against the exp5 composers fails, though that test is weak because the composer sets come from capital answers. Overall the "amplitude law" is **not supported as a law**. What stands is a 0.6B dose-response on a test-informed direction, a clean negative on back-patch-as-amplification, and a solid §2.3 method result: about 32 exact gates per layer close most of the first-order MLP gap. All are single seed, with small strata.
